# NeoMorse

«NeoMorse» is a simple web-based Morse code translator.

## Features

- Text → Morse
- Morse → Text
- Russian and English Morse alphabets
- Morse code table
- Audio playback
- Playback speed control
- Audio pitch control
- Stop playback
- Copy translated text
- Light and dark themes
- Mobile-friendly interface

## Languages

- HTML
- CSS
- JavaScript

## Version

Current version: 1.0
